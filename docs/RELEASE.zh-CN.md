## FAQ

**需要购买 CowTech 套餐吗？** 自托管核心访问不要求 CowTech 订单；第三方 API、采集、邮件和基础设施由采用者自备。

**不填 Key 能用吗？** 可以准备本地资料和配置，但依赖该服务的任务不能运行，不会自动出现真实监测结果。

**包括所有 AI 网站的接入吗？** 不包括这样的保证。实现、测试和实际可用状态见[功能矩阵](CAPABILITIES.zh-CN.md)。

**能保证品牌被推荐吗？** 不能。工具记录样本、组织内容行动和复测，不能控制平台答案。

**为什么留有 AIVGL、GEOFLOW、GEFLOW 配置名？** 它们是当前代码的兼容键，大小写和拼写要按实际入口保留；不代表连接 CowTech 服务，也不是新的公开产品名称。

**是否已通过安全审计或完整许可证审计？** 本发行已执行范围明确的凭据/数据扫描和来源许可工程核对，但不声称完成独立专业安全认证或所有历史权利鉴证。详见[发行审计](RELEASE-AUDIT.zh-CN.md)。

## v0.1.0 发布范围

- 独立干净快照，不携带旧私有 Git 历史、客户数据或运营配置。
- Apache-2.0 主许可证与第三方许可例外、必要声明。
- 统一 Docker 安装、空库初始化、独立凭据、内部认证与生产 CSS 构建。

- 未提供公网 TLS 托管、API 额度、供应商订阅或“所有平台均已实测”的承诺。

高级功能、跨版本升级/灾难恢复及未实测连接器的限制继续公开记录。版本发布不改变[功能状态](CAPABILITIES.zh-CN.md)中的证据等级。
