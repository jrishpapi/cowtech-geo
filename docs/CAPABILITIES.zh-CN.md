## 选择接入范围

如果只做资料与内容整理，不必同时订阅所有采集服务；如果观察网页回答，模型 API 的测试结果不能替代网页连接器验收。先验证一个明确的工作目标，再增加连接器和预算。

发行代码中保留兼容配置名，不意味着采用者必须使用历史品牌或 CowTech 托管服务。完整配置见[服务接入](INTEGRATIONS.zh-CN.md)。

## v0.1.0 接入责任

本发行交付配置入口、适配器和本地链路。外部 API、SMTP、网页会话和发布站点由采用者自行申请、配置和验收；没有将未实测功能改标为“真实平台通过”。完整操作见[使用者验收清单](OPERATOR-VALIDATION.zh-CN.md)。
