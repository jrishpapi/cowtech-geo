# 指标说明：分数衡量什么，不衡量什么

当前实现依据监测服务 `src/scoring.js`。所有分数截断在 0–100，保留两位小数；下面的比率取值 0–1。

## 分母和原始计数

N 为有 `parser_output` 的样本数。正式评分入口选择完成状态的回答。计数按“回答是否满足条件”，而不是把一条回答的多次提及重复累加。

| 符号 | 比率定义 |
|---|---|
| B | 提及目标品牌的回答数 / N |
| S | 含至少一个来源 URL 的回答数 / N |
| O | 含至少一个官方来源的回答数 / N |
| T | 含至少一个第三方来源的回答数 / N |
| C | 含至少一个竞争者来源的回答数 / N |
| M | 提及至少一个竞争者的回答数 / N |
| X | 未提及品牌但提及竞争者的回答数 / N |

这些条件可以重叠，不需要相加为 100%。官方/第三方分类是解析器的归类，不能代替来源内容的真实性审核。

## 当前公式

```text
可见度 = clamp(60B + 15S + 15O + 10T - 15X)
来源质量 = clamp(50O + 30T + 20S - 25C)
竞争压力 = clamp(60M + 40C)
clamp(x) = min(100, max(0, x))
```

可见度等级：A ≥ 85；B ≥ 70；C ≥ 50；其余 D。竞争压力越高表示竞争者存在感更强，不代表自身表现更好。“来源质量”是当前字段名称及启发式分数，并未自动证明引用来源可靠。

**重要局限：** S 和 T 统计回答中的来源，不只统计支持本品牌的来源。因此可见度分数不能简单解读为“品牌被推荐概率”。

## 零样本不是零表现

N=0 时当前函数返回 0 分与 D 等级，并附 `parsed_count=0`。解读报告时应标注“无可评分样本”，不能称品牌表现差。此说明不表示所有现有页面已完成零样本展示适配。

建议报告记录：计划问题数、尝试次数、成功回答数、成功解析数、失败/受限/不可用数、时间段、语言、地区和来源方式。不要在提升分数时隐藏采集成功率下降。

## 复测比较

保持品牌别名、问题集版本、来源类型、地区、语言、模型/供应商及设置可比。明确区分百分比相对变化和百分点差值；同时提供样本数。记录页面改动、发布时间和其它同期变化。

当前差值不是统计显著性检验，也不能排除平台更新、随机波动或其它内容活动的影响。流量与转化需要独立统计，不从可见度分数推算。
